# Информационная система рекрутингового агентства "RECRUITING"

Данный проект представляет собой информационную систему, разработанную на языке программирования Python с использованием PyQt5, предназначенную для автоматизации работы рекрутингового агентства. Система позволяет удобно управлять базой данных компаний-заказчиков, вакансий, резюме кандидатов, рекрутеров, навыков и воронкой найма.

## Функционал системы

- **Авторизация и разграничение прав доступа** (администратор/менеджер) с защитой паролей
- **Ведение справочников:**
  - Компании-заказчики (название, отрасль, контактное лицо, телефон, email, адрес)
  - Вакансии (должность, требования, зарплата, статус, компания)
  - Резюме кандидатов (ФИО, телефон, email, опыт, образование, ключевые навыки, ожидаемая зарплата, источник)
  - Рекрутеры (ФИО, должность, специализация, телефон, email)
  - Навыки (название, категория, вес)
- **Создание и управление воронкой найма** с возможностью добавления кандидатов и перемещения по этапам
- **Автоматический расчет процента соответствия** кандидата требованиям вакансии (TF-IDF)
- **Управление событиями** (собеседования, офферы)
- **Формирование отчетов:**
  - Отчет по закрытым вакансиям
  - Отчет по статистике воронки найма
- **Поиск по всем справочникам**
- **Смена пароля**

## Требования к системе

- Python 3.8 или выше
- Операционная система: Windows
